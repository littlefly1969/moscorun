# C4 — Feedback numerico

RPE, dolore, fatica, stress, qualità sonno, fame, motivazione, nutrizione e idratazione: metriche canoniche, valori nullable, range 0–10 per score e quantità non negative. Revisioni immutabili e tempo server tramite C2. Il servizio riceve l'identità autenticata dal chiamante.

Non implementa endpoint, questionari, testo libero, pasti strutturati, associazione a workout o consigli clinici. Le quantità non negative non costituiscono una validazione fisiologica.
