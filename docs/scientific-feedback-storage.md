# C4 — Feedback e nutrizione

Entry versionate con note testuali (massimo 4000 caratteri), riferimento workout autorizzato, RPE, dolore, fatica, stress, qualità sonno, fame, motivazione, nutrizione e idratazione. Score 0–10, quantità non negative e unità canoniche. Le osservazioni numeriche e l'intestazione della revisione si salvano nella stessa transazione. Replay identico non scrive; cambiamento richiede revisione nuova. Query per atleta, entry e cutoff temporale, incluse entry solo testuali.

Nessun dato reale nei test; non inviare le note a log. Il livello API/UI deve autenticare il chiamante, fornire ID entry stabili e presentare le revisioni, non interpretare come diagnosi i feedback. I dati testuali vanno trattati come contenuto non attendibile quando passati all'AI.
